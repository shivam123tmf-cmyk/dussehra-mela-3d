# Dussehra Mela 3D 🪔
Interactive night-time Dussehra mela you can walk around in the browser (Three.js). Rides, stalls, crowd, Ravan Dahan + fireworks, procedural Web Audio music.
All geometry, textures and sound are generated in code. Three.js r169 (MIT) is vendored in /vendor. No third-party art or audio assets.
